# 领域语言

本仓库自己的术语。通用编程概念不进这里；规格、草稿和实现细节各有各的去处。

**编号原语**：
与任何单据类型无关的号码生成机制——编号模板 DSL、Feistel 加扰、校验位、原子序列分配。业务无关；随能力层归 `idp-platform-go`，不进入框架（ADR-0011）。
_避免_：编号能力、编号服务、numbering capability

**平台能力**：
带自有数据表、目录或编排逻辑、意图跨应用复用的功能单元，如选项目录、单据类型目录、编号预留/认领。位于框架之上的能力层，归 `idp-platform-go` 库，不属于框架。
_避免_：平台组件、共享服务、平台功能

**技术表**：
框架拥有不可变迁移资产、与业务数据无关的基础设施表，如 `outbox`、`outbox_partition`、`inbox`。迁移执行、权限和历史归消费者。
_避免_：框架表、系统表
